# Case study voice

My writing voice as a skill, so an agent can draft or edit case-study copy that sounds like me:
warm, plain, first person and quietly funny.

**See it live:** the case studies on [yuvrajsingh.work](https://yuvrajsingh.work).

Written for my portfolio repo, so its paths point there. It's here to show how I brief an agent on
tone.

## What it holds

- **Facts come first.** Humour and colour come only from what actually happened. No invented
  anecdotes, quotes or numbers, and every number keeps its scope: who, which period, what it counts.
- **NDA rules.** No client names except the ones cleared, and no colleague names anywhere.
- **How it sounds.** Who's talking, sentence length, explaining a decision as rule, reason and
  example, and where humour goes: on the work, the process, the tools or me, never on the people the
  products serve.
- **Length and shape** for a case study, inside the reference portfolio's storyline.
- **Words that flatten the voice**, and a checklist to run before calling a draft done.
- **Examples:** real paragraphs from the site's first version, rewritten in the voice, with notes
  on why each change works.
